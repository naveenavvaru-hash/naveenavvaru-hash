## Featured project

### [MedTech Risk & Market Intelligence Pipeline](https://github.com/naveenavvaru-hash/Medtech-Risk-Intelligence)

A Python pipeline and Power BI report that turn public FDA data (adverse events, recalls, device registry, classification) into risk monitoring for medical devices.

- Bronze → Silver → Gold pipeline in Python and SQLite (star schema), fed by the openFDA API
- Risk-flagging engine using rolling baselines, z-scores and month-over-month velocity
- Automated quality gate on every export and 235 offline unit tests run through GitHub Actions
- 6-page Power BI report with DAX measures
